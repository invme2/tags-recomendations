APPLE.COM AESTHETIC — what to mimic
─────────────────────────────────────────────────────
Reference these existing PDPs while implementing (open in browser tabs):
  https://www.apple.com/iphone-air/
  https://www.apple.com/macbook-air/
  https://www.apple.com/airpods-pro/
  https://www.apple.com/shop/buy-iphone/iphone-15

Specifically:
1. FULL-VIEWPORT HERO. Eyebrow label (11-12px tracked uppercase) + H1
   that fills the viewport width (clamp(56px, 9vw, 128px)) + slim
   CTA pair (primary pill + secondary text link) + massive product
   photo. Hero takes ≥80vh on desktop.

2. SECTION RHYTHM IS CHAPTER-BASED. Each module reads as its own
   "chapter" with breathing room: padding-block clamp(120px, 16vw,
   200px). Sections feel deliberate, not stacked. White is default
   background. Reserve PURE BLACK sections for emphasis: the final
   CTA must be black-on-white-text, and every 5th content section
   inverts to black bg + white text for visual rhythm. NEVER pastel
   section backgrounds.

3. TYPOGRAPHY HIERARCHY:
   - Eyebrow: 11-12px, uppercase, letter-spacing .16em, color
     var(--ink-3). No serif italic.
   - H1 (hero): clamp(56px, 9vw, 128px), weight 600, line-height .95,
     letter-spacing -.04em. System / SF Pro Display.
   - H2 (section): clamp(40px, 6vw, 80px), weight 600, line-height
     1.02, letter-spacing -.035em.
   - H3 (story chapter / feature card): clamp(28px, 3.5vw, 48px),
     weight 600, letter-spacing -.025em.
   - Body: 17px / 1.55 / weight 400. Lead: 19-21px.
   - Use SF Pro Text / system-ui throughout. Keep Fraunces only if
     used VERY sparingly for one element type (e.g. stat numerals
     ONLY) — Apple itself uses SF Pro for everything.
   - DROP existing italic-em-via-Fraunces pattern in headings. Apple
     never italicises one word inside a sentence for emphasis.

4. APPLE PILL CTAs:
   - border-radius: var(--rounded-radius, 999px)
   - background: var(--btn-primary-bg-color, #0071e3) — Apple's blue
     as fallback (not pure --ink). #0071e3 is Apple's primary action.
   - color: var(--btn-primary-color, #fff)
   - padding: 12px 28px (mobile 14px 24px)
   - font-weight: 500, letter-spacing: -.005em, font-size: 17px
   - no box-shadow, no border (unless secondary)
   - hover: background var(--btn-primary-hover-bg-color, #0077ed),
     no transform (Apple buttons don't lift).
   - Secondary CTA: transparent bg, color #0071e3 fallback, "Learn
     more →" text style.

5. STICKY-SCROLL STORY. For wanelo-story.liquid: on desktop ≥1024px,
   each .wanelo-story-row becomes a 100vh section where text-column
   is position:sticky (top-aligned) and image-column scrolls past it
   (or vice-versa — mirror class alternates). On mobile, stack
   vertically without sticky (just standard rows).

6. STATS CLARITY. Replace current 2×2 fancy grid with single-row
   horizontal layout of 4 stat cells separated by hairlines (vertical
   on desktop, horizontal on mobile). Big numerals (clamp(48px, 7vw,
   96px)), weight 500, system font (NOT Fraunces — Apple uses SF Pro
   for numerals too). Label below: 12-13px tracked uppercase.

7. COMPARE / SIZE-GUIDE TABLES: clean Apple-Shop grids. Single
   hairline border, white cells, no zebra, no shadows. Hover row
   tints var(--bg-2). Column headers in BLACK on bg-2, uppercase
   tracked.

8. INTERLINKS / VARIANTS PILLS: flat, no shadow, no border. Just
   border-radius 999px with var(--bg-2) bg, hover var(--ink) bg with
   #fff text. Very Apple navigation chip feel.

9. NO DECORATIVE EMOJIS in markup. Replace existing glyph slots
   (features.glyph, care.glyph, gift-options icons) with one of:
   (a) SVG line icons inlined (12-line SVG library — see #11 below),
   (b) numeric counter (01, 02, 03 in Fraunces or SF), or
   (c) drop the glyph entirely and rely on typographic hierarchy.

10. SCROLL-LINKED HERO PHOTO. Hero photo translates Y at 0.4× scroll
    rate vs hero copy. Apple uses this on iPhone PDPs. Disabled on
    mobile (hero stacks). Disabled under reduced-motion.

11. ICON SYSTEM (replacement for decorative emojis): Inline a tiny
    SVG set in wanelo.css via CSS background-image data: URLs OR
    create snippets/wanelo-icons.liquid that defines named SVG
    symbols (use case attr in Designer JSON). Cover these slots:
    care: care-warm, care-cold, care-dry, care-iron, care-bleach,
          care-tumble, care-charge, care-store, care-wipe
    features: bolt, shield, check, sparkle, leaf, gem, infinity,
              clock, lock, ribbon (10 abstract icons)
    gift-options: gift, message, calendar
    Use stroke-based 1.5px lines, currentColor for inheritance.
    Total SVG payload: ≤2 KB inlined.

12. FONT LOADING. Stop @import-ing Fraunces unless you're keeping it
    for one specific element (numerals). Add system font stack first:
      -apple-system, BlinkMacSystemFont, 'SF Pro Display',
      'SF Pro Text', system-ui, sans-serif
    Apple-native devices render in actual SF Pro. Non-Apple devices
    fall back gracefully. No external font request.

13. MOTION BUDGET. Apple's motion is minimal:
    - opacity 0→1 + translateY 8-16px reveal on scroll (existing,
      tighten timing to 600-800ms cubic-bezier(.2,.7,.2,1))
    - hero photo scale 1.04→1 on initial reveal (1.6s)
    - hero photo scroll-parallax 0.4× rate (#10 above)
    - sticky story scroll (#5 above)
    - smooth FAQ expand 280ms (already in)
    - sticky mobile ATC bar (already in)
    NO: magnetic CTAs, count-up numbers (Apple doesn't do this on
    PDPs), cursor-aware lighting, particle effects, page transitions.

### FILE: pipeline/theme_assets/snippets/wanelo-product-schema.liquid

{%- comment -%}
  WANELO Augmented Product Schema (JSON-LD).

  Shopify themes emit a basic Product schema by default but it's
  inconsistent across themes and often missing key fields. This snippet
  emits a controlled, complete JSON-LD that helps Google build rich
  snippets in SERPs — +10-20% CTR for product pages already ranking.

  Compliance notes:
    - Does NOT emit `aggregateRating` from custom.reviews metafield —
      those are AI-generated content used for visual social proof, NOT
      verified buyer testimonials. Emitting them as schema.org aggregate
      ratings would be FTC fraud territory. Once Judge.me / Loox / Yotpo
      is wired with real reviews, this block can be expanded.
    - Does NOT emit `hasMerchantReturnPolicy` — operator handles return
      policy via a separate Shopify checkout-page module, not on PDP.

  Read fields:
    - product.title, product.vendor, product.url
    - product.price, product.compare_at_price, product.available
    - product.featured_image
    - product.metafields.custom.hero.value.lead (AI-written tagline,
      preferred over raw description for snippet quality)
{%- endcomment -%}

{%- assign hero_lead = product.metafields.custom.hero.value.lead | default: '' -%}
{%- if hero_lead == blank -%}
  {%- assign description_for_schema = product.description | strip_html | truncate: 300 -%}
{%- else -%}
  {%- assign description_for_schema = hero_lead | strip_html | truncate: 300 -%}
{%- endif -%}

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": {{ product.title | json }},
  "description": {{ description_for_schema | json }},
  "image": [
    {%- if product.featured_image -%}
      {{ product.featured_image | img_url: 'master' | prepend: 'https:' | json }}
      {%- for img in product.images limit: 5 offset: 1 -%}
        , {{ img | img_url: 'master' | prepend: 'https:' | json }}
      {%- endfor -%}
    {%- endif -%}
  ],
  "brand": {
    "@type": "Brand",
    "name": {{ product.vendor | default: shop.name | json }}
  },
  "url": {{ shop.url | append: product.url | json }},
  {%- if product.sku != blank -%}
  "sku": {{ product.sku | json }},
  {%- endif -%}
  "offers": {
    "@type": "Offer",
    "url": {{ shop.url | append: product.url | json }},
    "priceCurrency": {{ shop.currency | json }},
    "price": {{ product.price | money_without_currency | strip | replace: ',', '.' | json }},
    {%- if product.compare_at_price > product.price -%}
    "priceValidUntil": {{ 'now' | date: '%Y-12-31' | json }},
    {%- endif -%}
    "availability": "{% if product.available %}https://schema.org/InStock{% else %}https://schema.org/OutOfStock{% endif %}",
    "itemCondition": "https://schema.org/NewCondition"
  }
}
</script>

/* wanelo.js — sticky ATC + reveal-on-scroll + section rail */
(function () {
  'use strict';
  const page = document.querySelector('.wanelo-page');
  if (!page) return;

  const prefersReducedMotion = window.matchMedia &&
    window.matchMedia('(prefers-reduced-motion: reduce)').matches;

  /* ---------- Reveal-on-scroll ---------- */
  const revealTargets = page.querySelectorAll('.reveal, .mask');
  if (prefersReducedMotion) {
    revealTargets.forEach(el => el.classList.add('in'));
  } else if ('IntersectionObserver' in window) {
    const revealIO = new IntersectionObserver(entries => {
      entries.forEach(e => {
        if (e.isIntersecting) {
          e.target.classList.add('in');
          revealIO.unobserve(e.target);
        }
      });
    }, { threshold: 0.12, rootMargin: '0px 0px -50px 0px' });
    revealTargets.forEach(el => revealIO.observe(el));
  } else {
    revealTargets.forEach(el => el.classList.add('in'));
  }

  /* ---------- Section-progress rail (desktop only) ---------- */
  if (window.matchMedia('(min-width: 1100px)').matches && !prefersReducedMotion) {
    const sections = page.querySelectorAll(':scope > section');
    if (sections.length > 1) {
      const rail = document.createElement('div');
      rail.className = 'wanelo-rail';
      rail.setAttribute('aria-hidden', 'true');
      sections.forEach(() => {
        const dot = document.createElement('span');
        dot.className = 'wanelo-rail__dot';
        rail.appendChild(dot);
      });
      page.appendChild(rail);
      const dots = rail.querySelectorAll('.wanelo-rail__dot');
      // Position each dot proportionally along the rail track so 21
      // sections fit visually on a 280px-tall line rather than stacking.
      const total = sections.length - 1 || 1;
      dots.forEach((d, i) => { d.style.top = ((i / total) * 100) + '%'; });
      const railIO = new IntersectionObserver(entries => {
        entries.forEach(e => {
          if (e.isIntersecting) {
            const idx = Array.prototype.indexOf.call(sections, e.target);
            dots.forEach((d, i) => d.classList.toggle('active', i === idx));
          }
        });
      }, { threshold: 0.4 });
      sections.forEach(s => railIO.observe(s));
    }
  }

  /* ---------- Sticky mobile ATC ---------- */
  const atcAnchor = document.getElementById('wanelo-atc') ||
                    document.querySelector('product-form, [data-product-form], form[action*="/cart/add"]');
  if (atcAnchor && window.matchMedia('(max-width: 768px)').matches) {
    if (!atcAnchor.id) atcAnchor.id = 'wanelo-atc';
    const sticky = document.createElement('a');
    sticky.href = '#wanelo-atc';
    sticky.className = 'wanelo-sticky-atc';
    sticky.setAttribute('data-wanelo-atc-link', '');
    sticky.innerHTML = 'Add to cart <span class="wanelo-sticky-arrow">↑</span>';
    document.body.appendChild(sticky);
    const stickyIO = new IntersectionObserver(entries => {
      entries.forEach(e => sticky.classList.toggle('visible', !e.isIntersecting));
    }, { threshold: 0 });
    stickyIO.observe(atcAnchor);
  }

  /* ---------- Smooth-scroll for any [data-wanelo-atc-link] ---------- */
  document.querySelectorAll('[data-wanelo-atc-link]').forEach(link => {
    link.addEventListener('click', e => {
      const target = document.querySelector(link.getAttribute('href'));
      if (!target) return;
      e.preventDefault();
      target.scrollIntoView({
        behavior: prefersReducedMotion ? 'auto' : 'smooth',
        block: 'start',
      });
    });
  });
})();
